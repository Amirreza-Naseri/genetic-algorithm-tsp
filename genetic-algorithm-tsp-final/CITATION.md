# Method reference

The IPMX crossover and linear mutation operators implemented in this repository are based on:

Sharma, M. K., Chaudhary, S., Rathour, L., & Mishra, V. N. (2024). **Modified genetic algorithm with novel crossover and mutation operator for travelling salesman problem.** *Sigma Journal of Engineering and Natural Sciences, 42*(6), 1876–1883. https://doi.org/10.14744/sigma.2023.00105

This repository is an independent implementation and experimental extension for portfolio/educational use. The surrounding solver design, reproducibility controls, baselines, tests, CLI, and visualizations are part of this repository rather than claims about the paper's full experimental setup.
