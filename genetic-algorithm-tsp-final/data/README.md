# Data

`demo_cities.csv` contains the deterministic 30-city Euclidean instance used in the repository benchmark. It is generated by `src/run_experiment.py` with NumPy's `default_rng(seed=7)` and is included so the published results can be reproduced without external data.

For your own experiment, provide a CSV with `city,x,y` columns and run:

```bash
python src/run_experiment.py --coords data/my_cities.csv
```
