# Results

These files are generated by the default deterministic experiment:

- `benchmark_summary.csv`: headline benchmark metrics.
- `best_tour.csv`: visit order and city ID for the best GA tour.
- `convergence.csv`: best-so-far objective value per generation.
- `images/best_route.png`: route visualization.
- `images/convergence.png`: optimization history.
- `images/baseline_comparison.png`: comparison with simple baselines.

The benchmark is a synthetic 30-city Euclidean instance. The reported GA solution is heuristic and is not presented as the global optimum.
